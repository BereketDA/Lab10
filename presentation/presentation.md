---

### Цель работы
Получить практические навыки работы с редактором vi, установленным по умолчанию практически во всех дистрибутивах Linux.

---

### Что такое vi?
- Текстовый редактор, установленный по умолчанию в Linux
- Имеет три режима работы
- Работает в терминале
- Используется для редактирования файлов

---

### Три режима работы

| Режим | Назначение |
|-------|------------|
| Командный | Ввод команд редактирования и навигация |
| Режим вставки | Ввод текста |
| Режим последней строки | Сохранение и выход |

---

### Основные команды

| Команда | Действие |
|---------|----------|
| `i` | Вставка перед курсором |
| `a` | Вставка после курсора |
| `o` | Новая строка ниже |
| `x` | Удалить символ |
| `dd` | Удалить строку |
| `u` | Отменить действие |
| `:wq` | Сохранить и выйти |
| `:q!` | Выйти без сохранения |
